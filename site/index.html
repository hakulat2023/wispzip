压缩这件事，可以很轻

WispZip 是开源的极简文件压缩 / 解压工具：主界面只有一扇悬浮窗，拖进去就给确认页，格式、密码、分卷都收进折叠的「高级」。桌面壳是 Tauri 2 + Vue 3，下面是纯 Rust 的流式引擎。

常见操作不需要打开设置；真正复杂的格式能力留给 CLI 和折叠面板。

拖拽即用

拖普通文件进压缩确认页，拖归档进解压确认页。确认页只问「叫什么 / 放哪里」，其余全在高级里。

长在系统里

macOS 访达右键快速操作、Windows 右键菜单、双击关联文件直接进解压确认页；托盘常驻，最近任务可回看。

流式引擎

内存不随归档体积增长，可暂停 / 继续 / 取消；zip-slip 防护、GBK 文件名兼容、重名自动改名。

格式支持

一套 Rust 核心同时供桌面端与 CLI 使用，行为一致。

FormatCompressExtractNotes
zipYesYesDeflate 0–9, AES-256, ZIP64, UTF-8 / GBK filenames
tarYesYesPreserves permissions and mtime
tar.gz / tar.bz2 / tar.xz / tar.zstYesYesStreaming pipeline with live progress
gz / xz / zst / bz2YesYesSingle-file stream compression
7zYesYesLZMA2 0–9, AES-256, Unix permission bits
rarNoYesrar4 / rar5, including encrypted archives
Split volumesYesYesByte-level .001/.002 volumes, streamed on both sides

分卷压缩与解压都不生成整包临时文件，峰值磁盘约为归档体积的 1 倍而不是 2 倍。RAR 是唯一例外：UnRAR 只接受真实文件路径，卷集仍需先拼接。

macOS 首次打开请先读
App 未经 Apple 公证（无开发者账号），下载后带隔离属性，首次打开可能提示「已损坏」或「无法验证开发者」。执行一次 xattr -cr /Applications/WispZip.app，或右键 App → 打开即可，之后不再提示。Windows / Linux 产物解压即用。
